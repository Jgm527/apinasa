  "caption": "Earth imagery captured by EPIC",
  "image": "epic_1b_...",

D

JSON para datos, archivo para imágenes

El endpoint consultado devuelve una colección de metadatos. Cada elemento describe una imagen mediante `identifier`, `date`, `caption` y coordenadas; la propiedad `image` identifica el archivo asociado.
